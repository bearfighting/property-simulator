# UI 输入与默认值

本文记录模拟创建和运行期间由用户界面提供的输入规则。UI/UX 细节仍可迭代；这里仅固定输入归属和当前已讨论的默认场景。

## 输入责任

- 用户输入、用户命令、Slice 启用选择及其默认值由 Presentation/UI 收集或提供。用户可以接受默认值而不逐项填写。
- Application 接收 UI 提交的完整 context 和命令，负责用例流程、持久化和向单月计算传递明确参数。Application 不定义产品默认值，也不从 Core 推导用户设置。
- Core 只验证计算所需的不变量并执行计算。用户未启用的 Slice 不参加该月计算，不产生事件、状态变化、Ledger 交易或现金流影响；未启用 Slice 的专属参数不要求填写。
- 用户在模拟期间可以更新设置、启停 Slice，或提交停止命令。更新后的 context 用于后续月份；已完成月份仍保留当月实际生效输入。

## 可直接运行的默认场景

用户不修改任何字段也可以开始模拟。UI 提供以下建议默认值，并允许用户调整：

| 输入 | 建议默认值 |
|---|---|
| 默认货币 | CAD，可由用户调整 |
| 房产价格 | CAD 1,000,000 |
| 贷款期初余额 | 房价的 70% |
| 固定年利率 | 5% |
| 剩余还款期限 | 240 个月 |
| 期初现金 | 0 |
| 房屋状态 | 可用 |
| 未配置的租金金额 | 0 |
| 贷款 Slice | 默认启用，以匹配默认的“贷款全部清零”停止条件 |
| 其他 Slice | 可由用户启用；未启用的 Slice 不影响模拟 |

房产价格和贷款参数是房产估值及贷款期初事实，不是 Core 或 Application 生成的隐式状态。默认值由 UI 明确填入提交的 context。

## 停止条件

首版只提供两类停止条件：

- 用户设定的模拟月数。
- 贷款全部清零。

默认启用“贷款全部清零”。用户可只选期限，也可同时选择两者；多个条件采用 OR 语义，任一满足即停止。若用户同时设置期限和贷款清零，以先满足者为准。模拟期间用户也可通过命令停止。

若用户关闭所有贷款 Slice，则“贷款全部清零”不再是有效停止条件；UI 应要求用户设置模拟月数后才能开始，避免没有可达停止条件的模拟。

## 暂不要求的用户资料

当前计算没有使用的房产地址、面积、购入日期、家庭成员或其他背景资料不作为必填输入。新增输入须对应明确的计算或呈现用途。

## 与 Application 的交互

UI 仅通过 Application 的四类用例操作与模拟交互：设置初始值、推进一个月、获取统计报告、读取指定月份完整结果。月度推进请求可一并携带本月生效前的设置变更或停止命令。UI 回看某月时读取已经保存的完整结果及其 snapshot，不要求重新运行该月计算。
