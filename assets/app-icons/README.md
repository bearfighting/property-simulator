# Desktop application icon

This project-only icon set contains the PropOrbit desktop application icon:

- `prop-orbit.svg` is the editable vector master.
- `prop-orbit.ico` is the multi-resolution Windows icon.
- `prop-orbit-{size}.png` are Linux/package exports from 16 px through 1024 px.

The complete brand, feature, product-card, and guide asset pack is kept outside
this repository at `~/Downloads/PropOrbit-Polished-Assets`.
